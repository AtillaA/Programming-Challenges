Processes are arranged in a tree and numbered starting from 1 in the order they are created. 
Process n creates exactly n child processes, and child processes are numbered sequentially as they are created.
You are given a processorNumber where processorNumber > 1. 
Your task is to determine the parent process number of this process. 

Constraints
-----------
2 ≤ processNumber ≤ 10^9
